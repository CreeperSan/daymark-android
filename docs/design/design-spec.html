Daymark Design System

纪念日应用设计规范

一套面向多端（Android / iOS / Windows / macOS / Web）的纪念日应用设计系统。 以「晨间记事本」为视觉隐喻——阳光洒在书桌上翻开的日记本，温暖、安静、精致。

字体排印

12 级字号 · 4 级字重 · 5 级行高

字体家族

Inter 作为拉丁字体，现代、易读、中性，不抢戏。 Noto Sans SC 作为中文字体，与 Inter 视觉气质一致、字重覆盖完整。 两者搭配，中英混排自然、编号与数字清晰。

/* 字体栈 — 中文优先以确保标点与全角符号正确 */ --font-sans: "Inter", "Noto Sans SC", "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei UI", system-ui, -apple-system, sans-serif; --font-mono: "JetBrains Mono", "SF Mono", ui-monospace, monospace; --font-num: "Inter", "Noto Sans SC", system-ui, sans-serif;

阴影系统

纸张质感 · 柔和扩散

阴影取「纸面浮起」的意象：柔和、扩散、不刺眼。 基于暖色 rgb(42,36,29) 调色，不用纯黑，避免冷硬感。 两级高度：Flat（默认无阴影）+ Raised（悬停/浮起），不过度堆砌层级。

07

动效系统

像翻页一样自然 · 5 级缓动 · 4 级时长

动效性格：温和、有节奏感，像翻书页一样自然。 不用弹跳物理效果、不用视差滚动、不在每处都加淡入。 一个页面对应一个有目的的动效——触觉反馈、结果揭示、状态过渡。 始终支持 reduced-motion。

标准减速 · Standard cubic-bezier(0.4, 0, 0.2, 1) · 250ms
强调入场 · Emphasized cubic-bezier(0.2, 0, 0, 1) · 400ms
减速 · Decelerated cubic-bezier(0, 0, 0.2, 1) · 250ms
加速退场 · Accelerated cubic-bezier(0.4, 0, 1, 1) · 150ms
弹性 · Spring（仅用于触觉反馈） cubic-bezier(0.34, 1.56, 0.64, 1) · 400ms
