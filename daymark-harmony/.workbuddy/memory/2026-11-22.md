# 2026-11-22

## 纪念日（Daymark）鸿蒙版：视觉打磨与核心链路验证

### 沉浸式与系统栏
- `EntryAbility` 增加 `setWindowLayoutFullScreen(true)` + 系统栏透明，并把状态栏/底部安全区高度写入 `AppStorage`（`topInset` / `bottomInset`）。
- 页面内容在 `pages/Index.ets` 统一 `padding({ top: topInset })` 让开状态栏，背景用 `expandSafeArea` 铺满整屏。
- 主题切换后由 `AppSettings.onSystemBarsDirty` 回调触发系统栏重绘，避免浅色背景配白色图标。

### ArkUI 踩坑（重要，后续不要再试）
- `Shape` + `Path`：坐标按固定像素绘制，不随组件尺寸缩放，图标大小失控。
- `Image.fillColor`：只覆盖 SVG 的 `fill`，改不了 `stroke`，描边图标永远是黑色。
- `Image.colorBlend`：会把整个矩形染色，不能用于图标。
- SVG 没有 `width/height` 时按内部坐标系渲染，实际显示约为组件尺寸的 37%，图标普遍偏小（页面状态图标可用 `glyphSize ≈ 100` 补偿）。
- 自定义组件上挂链式通用属性（`.width()` 等）无效，必须用组件自己的 `@Prop`。
- `Column` 默认居中对齐，Scroll 里的内容不满一屏时也会垂直居中；需要显式 `alignItems(HorizontalAlign.Start)` 与 `constraintSize({ minHeight: '100%' })`。
- 密码输入框会拉起「安全键盘」，此时系统禁止截屏（截图全黑），不是崩溃。

### 业务实现要点
- 语言切换：`I18n` 是静态字典，切换后已存在的页面不会重建，因此 `Index` 用 `uiEpoch` + `ForEach` 换 key 重建整棵导航树；各页面额外接收 `langTag` 触发重建。
- `AnniversaryStore` 是普通单例，字段变化不会触发刷新，HomeView 用 `loadingList / loadError / offlineState` 等页面状态镜像后才能正确切换空态/错误态。
- `GlassPrimaryButton` 禁用态不能用 `.enabled(false)`（系统会整体调暗），改为拦截 onClick + `stateEffect`。

### 图标方案
- 图标统一由 `.tools/gen_icons.py` 生成「纯填充 SVG」到 `resources/base/media/ic_*.svg`，运行时用 `fillColor` 换色。
- 注意：`gen_icons.py` 是图标唯一来源，改图标要改脚本后重跑，不要手改 svg。

### 调试脚本
- `.tools/dev.sh`：build / shot / dump / tapText / tap / swipe / log（依赖 `MSYS2_ARG_CONV_EXCL=*`，否则 Git Bash 会改写设备路径）。
- `.tools/find.py`：按文字在 `uitest dumpLayout` 结果里查控件中心坐标，用于稳定点击。
- 设备包名 `com.creepersan.daymark`；HAP 未签名可直接 `hdc install -r`。

## 第二轮：布局与法务链接修正（用户逐条反馈）

- **首页间距**：`List` 的 `space` 只对 `ListItemGroup` 之间生效，**组内卡片完全不生效**（实测 ListItem 边界首尾相接）。改为给每个 `ListItem` 加 `.margin({ bottom: CARD_GAP })`，分组标题 `margin.top = GROUP_GAP - CARD_GAP`，得到 14vp 组内间距、22vp 组间间距。
- **转场重叠**：`NavDestination` 默认透明，推入页能透出上一页内容（截图里两页叠在一起）。在 `Index.destination()` 里给每个页面套 `Stack` + 自绘渐变 `pageBackground()`，并 `expandSafeArea` 覆盖状态栏/手势条，页面才是整块不透明。
- **底部弹层**：`bindSheet` 写死高度会留白或截断最后一项，改用 `detents: [SheetSize.FIT_CONTENT]`；内容 `padding.top = 34`（让开 dragBar）、`padding.bottom = 32 + bottomInset`。
- **Scroll 内容居中**：`Scroll` 内容不足一屏时默认垂直居中，编辑页 / 账号页 / 改密页都必须 `constraintSize({ minHeight: '100%' })` + `justifyContent(FlexAlign.Start)`。
- **日期弹层**：移除内部公历/农历分段控件与底部摘要（历法只由外部决定），农历年份用 `LunarLabels.yearLabel()` 输出「甲辰龙年（2024）」；年份列需更宽权重且字号调小，否则长标签换行把行高顶开（`WheelColumn` 新增 `itemFontSize` / `activeFontSize`，并 `maxLines(1)`）。
- **法务链接**：隐私政策 `blog.creepersan.com/article/64`、服务协议 `/65`，统一放在 `common/LegalLinks.ets`；设置页两行分别打开、关于页拆成两个可点文本、注册页协议行拆成「《服务协议》与《隐私政策》」两个可点链接。
- **登录页**：注册入口从 `Blank()` 推到底部改为紧跟表单并 `justifyContent(Center)`；设置入口改成品牌图标右侧的齿轮按钮（登录前也能切主题/语言）。
- **找回密码页**：去掉注册入口，只保留注册页的「已有账号？去登录」。

## 第三轮：沉浸背景断层 + 应用图标

- **断层根因**：`Navigation` 的 `padding({top: topInset})` 会同时作用到 `NavDestination`，导致目的页自绘背景从状态栏下方才开始画；而背景又用了「纯线性渐变」，没有根背景的柔光，于是状态栏下方出现一条明显的颜色/结构分界（首页是 navBar，不受影响，所以只有二级页出问题）。
- **修法**：Navigation 不再加 padding，改为把 navBar 内容包一层 `Column.padding({top: topInset})`；目的页里 `Stack` = `GlassBackground`（同一组件、从 y=0 绘制，柔光也对得上）+ 一个 `padding({top: topInset})` 的内容列。实测设置/注册/编辑/关于页与首页同坐标色差 ≤3。
- **教训**：给 `NavDestination` 做不透明背景时，不要用「近似色」自绘，直接复用根背景组件，否则永远调不齐。
- **图标**：新增 `.tools/gen_icon.py`，用品牌渐变 + `ic_heart.svg` 的心形路径生成 AppScope/entry 的 `background.png`、`foreground.png`（1024 分层图标）与 `startIcon.png`（带圆角 456px）。图标只改脚本，不要手改 png。
- **创建账号页**：去掉底部「已有账号？去登录」。
