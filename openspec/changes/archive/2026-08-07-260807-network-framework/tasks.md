## 1. 依赖与模块骨架

- [x] 1.1 确认 Retrofit 3 正式稳定版与 Kotlin 1.8.10、AGP 8.1.0、OkHttp 的兼容性，并在 `app/build.gradle.kts` 添加协程、Retrofit、OkHttp、JSON 转换、protobuf、SSE 和 MockWebServer 所需依赖。
- [x] 1.2 创建独立的 `network/api`、`network/core`、`network/middleware`、`network/transfer`、`network/internal` 包，明确公开 API 与 internal 实现的可见性边界。
- [x] 1.3 为新增公开类型、公开方法和复杂控制流补充简体中文 KDoc 与关键逻辑注释，并配置静态检查以防止网络包依赖 RxJava 或 Android UI。

## 2. 客户端与请求配置

- [x] 2.1 实现不可变的 `NetworkClientConfig`、`NetworkClientBuilder` 和 `NetworkClient`，支持基础地址、超时、默认请求头、转换器、OkHttp 客户端和全局中间件配置。
- [x] 2.2 将 Retrofit 3 服务创建接入 `NetworkClient`，并实现按有效配置安全复用客户端、不同客户端互不污染的策略。
- [x] 2.3 实现 `RequestSpec`、可选参数和请求验证，支持方法、路径、查询参数、请求头、标签、请求体、目标类型及单请求超时覆盖。
- [x] 2.4 实现配置失败的 `NetworkFailure` 分类与脱敏诊断信息，覆盖非法基础地址、非正超时、载荷不兼容和缺失编解码器。

## 3. Flow 执行与中间件

- [x] 3.1 定义 `NetworkEvent`、`NetworkFailure` 和取消语义，确保请求 Flow 为冷流、每次收集独立执行且只产生一个终态。
- [x] 3.2 实现基于 `channelFlow` 或 `callbackFlow` 的请求执行器，将 OkHttp 调用、响应关闭、子协程和文件资源的创建与清理纳入同一结构化并发边界。
- [x] 3.3 定义可挂起的中间件 SPI、独立 `RequestContext` 和 `MiddlewareOutcome`，支持继续、短路成功、拒绝失败与取消。
- [x] 3.4 实现全局和请求级中间件链的下行/回程顺序、挂起恢复与短路，保证未发送请求被终止时不会创建底层网络调用。
- [x] 3.5 实现收集协程、显式请求和中间件终止的取消传播，确保取消等待中的鉴权、传输和持续连接时均释放资源且不误报成功。
- [x] 3.6 实现可注入且默认脱敏的网络日志与关联标识记录，禁止认证头、Cookie、文件内容及敏感查询参数进入默认日志和错误文本。

## 4. 载荷、文件与持续事件传输

- [x] 4.1 实现 `PayloadCodec` SPI 及 JSON、URL 编码表单、Multipart、protobuf 和二进制的请求编码、响应解码与媒体类型匹配校验。
- [x] 4.2 实现上传 `RequestBody` 包装器，按可配置字节或时间阈值发射单调上传进度，并正确处理未知总长度。
- [x] 4.3 实现下载流包装、临时文件写入、完整性验证和原子提交；在成功、失败与取消路径关闭资源并清理或保留临时文件。
- [x] 4.4 实现可选断点恢复下载：构造范围请求、验证服务端响应后追加数据，并在不支持范围请求时按声明策略重新下载或失败。
- [x] 4.5 实现独立 SSE 传输器，解析事件帧、暴露事件名称/标识/数据/重连提示，并支持取消关闭和受限的最后事件标识重连。
