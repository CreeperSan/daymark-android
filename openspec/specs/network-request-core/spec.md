# network-request-core Specification

## Purpose

为 Android 应用提供可复用、不可变且与具体 HTTP 实现解耦的请求描述、响应解码、错误表达和调用入口。

## Requirements

### Requirement: 请求描述必须可复用且配置完整
系统 SHALL 支持通过不可变请求描述配置主机、路径、HTTP 方法、请求头、查询参数、路径参数、请求体、中间件、响应模式和类型化自定义属性。请求描述在执行期间不得因外部集合修改而改变。

#### Scenario: 复用同一请求配置
- **WHEN** 调用方使用同一请求描述发起两次请求
- **THEN** 两次执行使用相同初始配置，并拥有彼此隔离的执行上下文

### Requirement: 传输实现必须可替换
系统 SHALL 通过稳定的传输抽象执行请求，核心公开 API 不得要求调用方依赖具体 HTTP 客户端、序列化库或响应体类型。

#### Scenario: 替换传输实现
- **WHEN** 测试环境注入模拟传输实现
- **THEN** 请求、中间件和响应解码行为无需修改即可执行

### Requirement: 错误必须结构化且安全
系统 SHALL 区分配置、连接、超时、HTTP 状态、解码、业务、文件、SSE 和取消错误，并保留可诊断关联标识；默认错误文本不得包含认证信息、Cookie、密码或完整敏感载荷。

#### Scenario: 服务端返回 HTTP 错误
- **WHEN** 传输收到非成功 HTTP 状态
- **THEN** 系统产生包含状态码和安全摘要的 HTTP 错误，且不产生成功结果
