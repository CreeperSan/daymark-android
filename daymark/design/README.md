# 纪念日设计规范

设计来源：[Ardot《纪念日》](https://ardot.tencent.com/file/745109728176283)。`screens/` 为 2026-11-08 导出的页面快照，便于离线核对；原始文件仍是设计真源。截图中的姓名、邮箱、数量和版本号仅为示例，不应作为产品数据。

## 视觉

- 以浅奶油、蜜桃和暖橙为主；背景为暖色纵向渐变，叠加玫瑰、淡紫和琥珀色的大范围柔和光斑。暗色模式使用深棕紫背景和低透明度暖色光斑。
- 亮色文字主色 `#4A2511`，次要文字 `#A5795C`，强调色 `#FF6A45`；按钮渐变从 `#FF9459` 到 `#FF6B52`。暗色应分别保证文字和边界对比度。
- 玻璃卡片为半透明浅色填充、细白描边和大圆角；iOS 26 及以上使用系统 Liquid Glass，旧系统使用材质回退。Android 不使用 Material 的水波和默认控件外观。
- 常见页面水平边距 20–24，导航栏高度 52，圆形返回按钮 36；列表标题 15、辅助文字和分组标题 12、设置行文字 14。单位为 Android dp/sp 或 iOS point。
- 主按钮高 54、圆角 27；首页列表卡片圆角 20、内边距 16；输入框圆角 16。以上尺寸以设计稿为基准，需适配系统字体缩放和小屏幕。

## 交互

- 标题栏固定；长列表可滚到标题栏和系统栏后方，使用不遮挡操作的渐变或渐变模糊维持可读性。
- 主题、语言和代理等配置通过模态弹窗；未实现的设计入口保留并明确提示开发中。
- 首页按今天、即将到来和已经过去分组；编辑日期支持公历、农历及闰月。设计中的人物、纪念日和数值不可替代真实数据。
- Android 保留经典版及独立本地数据，经典版可从底部切回新版；iOS 不提供经典版、模式切换和经典数据导入。
- 协议与隐私政策目前暂时指向用户指定的同一链接，正式发布时应替换。
