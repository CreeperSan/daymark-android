# 纪念日 iOS

使用 Xcode 打开 `Daymark.xcodeproj`，选择 `Daymark` scheme 运行；最低支持 iOS 18。iOS 26 及以上使用系统 Liquid Glass，较早版本使用系统材质回退。页面和设计规范见 `../daymark/design/`。

账号会话保存在设备钥匙串；账号和纪念日请求分别使用 Android 版相同的服务端接口。快速连续点击设置页标题 8 次开启开发者设置，代理地址支持 HTTP 和 HTTPS，关闭开发者模式后恢复默认服务地址。模拟器访问本机服务可使用 `http://127.0.0.1:8080`；真机需要与电脑处于同一网络，使用电脑的局域网 IP，并确保服务监听该网卡及防火墙允许连接。HTTP 明文传输数据，请仅在可信的开发环境中使用。iOS 不包含经典版及经典数据导入。

`DaymarkTests` 包含农历、循环日期和本地模拟网络请求测试，可通过 Xcode 的 Test 操作运行。第三方登录、部分个人信息设置以及尚无译文的语言内容仍需后续完善；未完成入口会提示开发中，缺失翻译回退中文。用户协议和隐私政策暂时使用同一个占位链接，正式发布前需要替换。
